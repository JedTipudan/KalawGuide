ALL FREE

Put KalawGuide online

Step-by-step guide to publish the KalawGuide website for free on Vercel, plus an optional free Android APK for the hackathon demo. Tick the boxes as you go. Your progress is saved in this browser.

What you will end up with
  • A public website, e.g. https://kalawguide.vercel.app, that works on laptops and phones.
  • Automatic re-deploys every time you push to GitHub.
  • (Optional) An Android .apk download link you can share or turn into a QR code.
Read this first: where the data lives

KalawGuide stores its data in a SQLite database inside each visitor's browser. There is no shared server. On the live site:

  • Every visitor starts with the same seeded demo data (destinations, the default admin account, and so on).
  • Accounts, trips, budgets and expenses someone creates stay on their own device and browser. Other people won't see them.
  • An admin approving a business on one laptop won't change what tourists see on their phones.

This is fine for a hackathon demo. Explain it during Demo Day if the judges ask. Sharing data between users would need a backend, and that's outside the free setup.

1. Prepare the repository

The project already includes the one file Vercel needs:

FileWhat it does
vercel.jsonTells Vercel how to build the site (npx expo export -p web → dist). Sends the two security headers that the browser database (expo-sqlite) needs, without which the app can't load its data. Also sends every page path to the app, so refreshing /explore works instead of showing "404".
  2. git add -A
git commit -m "Prepare web deployment"
git push origin main

2. Deploy on Vercel (recommended)

Vercel's free Hobby plan covers personal and non-commercial projects like this hackathon. Once connected to GitHub, it rebuilds the site automatically after every push.

Updating the site later: just git push to main. Vercel rebuilds and publishes on its own. Pushes to other branches get their own preview link. Watch progress under Deployments.

3. Alternative: deploy from your computer (Vercel CLI)

Use this if you don't want to connect GitHub.

  1. npx vercel login
  2. npx vercel --prod

5. Google Sign-In on the live site

Without a Google client ID the app uses demo mode, which is fine for the hackathon. To use real Google accounts:

The database header Cross-Origin-Opener-Policy: same-origin can stop a Google sign-in popup from passing the login back to the site. If Google Sign-In fails on the live site, use email sign-in or demo mode for the demo. Don't remove the header: the app's data needs it.

6. Optional: free Android APK

The hackathon is about a mobile app, so a real Android install is a strong demo. Expo's free plan includes a limited number of cloud builds each month. You don't need Android Studio.

  2. npx eas-cli@latest login
  3. npx eas-cli@latest build -p android --profile preview
    When it asks to create the project and generate a keystore, answer Yes.

7. Live map (mobile and web)

KalawGuide has a free live map that works the same in the app and on the website. It doesn't need an API key or a paid account.

WhereWhat you see
Map page
Mobile: Home → 🗺 Live map
Web: top menu → Map (or /map)		Every destination as a pin, plus a pulsing blue dot that follows your real GPS position. Tap a pin → View details. ◎ centres on you, ⤢ shows all places.
Destination pageA map of that place with your live position, "X km away", and a Get directions button. The button opens Google Maps turn-by-turn directions for free (the app if installed, otherwise the website).
What it's built from (all free): Leaflet (map library) + CARTO map tiles (OpenStreetMap data, free for non-commercial use as long as the credit in the corner stays visible) + expo-location for GPS. The map's code lives in components/map/ and features/map/useLiveLocation.ts.

9. Troubleshooting

ProblemFix
Blank page, or the console says SharedArrayBuffer is not definedThe headers aren't being sent. Check that vercel.json is committed at the project root, and that Framework Preset is Other. Redeploy.
"404: NOT_FOUND" after refreshing a pageThe rewrites rule in vercel.json is missing. Commit it and redeploy.
Build fails during installCommit package-lock.json together with package.json. Under Settings → General → Node.js Version, choose 22.x.
Changes don't show upCheck Deployments for a failed build. Hard-refresh the browser (Ctrl+Shift+R).
Map is grey or has no streetsThe device is offline, or a school network is blocking basemaps.cartocdn.com / unpkg.com. Try mobile data.
Map shows "Location permission is off"Allow location for Expo Go or the browser in your phone settings, then tap the message to retry.
Blue dot never appears on the websiteOpen the site over https:// (Vercel) or localhost, not a http://192.168… address.
My data disappearedData lives in each browser. Clearing site data, private windows, or a different device each start fresh from the demo seed data.
